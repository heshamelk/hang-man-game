# Hangman Game

## Description
A simple Hangman game built using HTML, CSS, and JavaScript. The player guesses letters to complete a hidden word before making too many mistakes, leading to the hangman's completion.

## Features
- Interactive UI with a hangman drawing that updates as the player makes mistakes.
- Randomly selects words from different categories (e.g., movies, persons, countries, colors).
- Tracks user progress and limits incorrect guesses to 8 attempts.
- Visually disabled letter buttons after they are clicked.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)

## How to Play
1. The game randomly selects a word from a specific category.
2. The category is displayed to give the player a hint.
3. The player clicks on letters to guess the word.
4. Correct guesses fill in the word, while incorrect guesses add parts to the hangman drawing.
5. The game ends when the player completes the word or makes 8 incorrect guesses.

## File Structure
```
project-folder/
│── index.html       # Main HTML file
│── style.css        # Stylesheet for UI design
│── main.js          # JavaScript logic for game functionality
```

## Installation & Usage
1. Clone or download the repository.
2. Open `index.html` in a web browser.
3. Start playing by clicking on the letter buttons.
